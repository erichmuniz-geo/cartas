# Cartas & Extratos — PWA para celular e GitHub Pages

Pacote estático, sem dependências externas. Pode ser publicado diretamente no GitHub Pages.

## Estrutura
- **Português**: 44 arquivos em 16 anos/pastas.
- **Español**: 267 arquivos em 16 anos.
- **Extratos**: 56 arquivos em 5 anos.
- Pesquisa por nome do arquivo dentro da pasta selecionada.
- Visualização interna de JPG/PNG/WebP.
- ODT e outros formatos compatíveis são abertos pelo aplicativo do dispositivo.
- PWA instalável quando publicado por HTTP/HTTPS.
- Cache local do aplicativo e dos arquivos abertos recentemente (até 60 documentos do acervo).

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie **o conteúdo desta pasta** para a raiz do repositório, preservando `assets/`, `acervo/` e os demais arquivos.
3. Em **Settings → Pages**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Aguarde a URL HTTPS gerada pelo GitHub Pages.

## Instalar no celular
### iPhone / iPad
Abra a URL no Safari → Compartilhar → **Adicionar à Tela de Início**.

### Android
Abra a URL no Chrome → menu → **Instalar app** ou **Adicionar à tela inicial**.

## Uso local
O catálogo e os arquivos podem ser abertos diretamente por `index.html`. Os recursos PWA (instalação e cache offline) exigem HTTP/HTTPS.

## Observação de tamanho
Nenhum arquivo individual do acervo ultrapassa 100 MB. O pacote completo é grande porque preserva as digitalizações originais para manter a legibilidade.
